# Трекер привычек (Habit Tracker)

Приложение для отслеживания ежедневных привычек и прогресса.

## Описание
Проект помогает пользователям:
- Создавать и отслеживать привычки
- Вести статистику выполнения
- Анализировать прогресс

## Структура проекта
- `project-notes.md` - заметки по проекту
- `api-plan.md` - план API
