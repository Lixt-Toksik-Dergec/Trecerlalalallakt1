# Заметки по проекту

## Проект: Трекер привычек

### Описание
Приложение для отслеживания ежедневных привычек.

### Функции:
- Добавление новых привычек
- Отметка выполнения за день
- Просмотр статистики
- Напоминания

### Технологии:
- Python/JavaScript (выбери что используешь)
- База данных SQLite
